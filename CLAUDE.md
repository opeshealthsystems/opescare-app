# OpesCare — patient and clinician mobile app

The **OpesCare** mobile app (Expo SDK 57 / React Native, package
`com.opescare.patientid`, version 1.5.0): drug & blood finder, appointment
booking, facility directory, portable **Health ID**, records, consent, family
and clinician desks. Forked from the OpesCare platform patient app; it talks to
the Finder backend, now served at **opescare.com** (`https://opescare.com/api`,
formerly finder.opescare.cloud; override with `EXPO_PUBLIC_API_BASE_URL`).
Start with `README.md` and `docs/ARCHITECTURE.md`.
