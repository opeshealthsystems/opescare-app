## Writing the next one

Two rules this project already follows elsewhere, and they apply here:

1. **Say what changed for the person holding the phone**, not what changed in
   the repository. "Appointment reminders now arrive" is a release note;
   "fixed the observer that schedules reminders" is a commit message.
2. **Never describe availability as confirmed.** Facilities report stock and it
   is timestamped; the app has never claimed more than that, and a release note
   is not the place to start.
